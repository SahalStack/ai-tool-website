# 🤖 AI Tool - Static Website
**AI Tool** is a clean and modern static website built using **Tailwind CSS**. It is ideal for showcasing AI products, tools, or services with a visually appealing layout and professional design.

---

## ✨ Features

- ⚡ Static website with fast load time
- - 🎨 Modern UI using Tailwind CSS
- 🧩 Clean and organized code
- 🖼️ Designed to highlight AI-focused content
- 🔍 SEO-friendly HTML structure

  
  ## 🧰 Tech Stack

- **HTML5**
- **Tailwind CSS**
- **Heroicons** (for icons)
- **Google Fonts**
